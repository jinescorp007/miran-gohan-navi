# ミランごはんナビ（試作版）

## 主な機能
- レストランメニューの撮影・画像選択
- ブラウザ内OCRによる文字読み取り
- アレルギー設定との照合
- 「候補／要確認／避ける／情報不足」の色分け
- 店員さんに見せる確認文章
- 食事・症状メモ
- iPhone/Androidのホーム画面に追加可能なPWA

## 重要
このアプリは医療機器ではなく、安全を保証しません。
外食時は必ず店舗スタッフに原材料、調味料、調理油・器具の共用を確認してください。
血液検査結果だけで除去食品を決めず、医師の指示に基づいて設定してください。

## 公開方法
各ファイルをGitHubリポジトリのルートへアップロードし、
Cloudflare Pagesなどで公開してください。

## 初回OCR
OCRライブラリをインターネットから読み込むため、初回は通信が必要です。
